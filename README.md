## Deskripsi Program

### 1. Sistem Pengelolaan Nilai Mahasiswa
Deskripsi:
Program ini dibuat untuk menyimpan dan mengelola data mahasiswa yang berisi NIM, nama, dan nilai. Di dalam program ini terdapat fitur untuk menambahkan data, mengurutkan nilai, dan mencari data mahasiswa. Struktur data yang digunakan yaitu Dynamic Array, Single Linked List, Insertion Sort, Linear Search, dan Binary Search.

### 2. Sistem Antrean dan Pengelolaan Buku Perpustakaan
Deskripsi:
Program ini dibuat untuk mengatur antrean peminjaman dan pengembalian buku di perpustakaan. Pengguna bisa menambahkan antrean, memproses peminjaman, melihat riwayat pengembalian, dan mencari ID buku. Program ini menggunakan Queue, Stack, dan Binary Search Tree (BST).

### 3. Sistem Pencarian Rute di Lingkungan Kampus
Deskripsi:
Program ini dibuat untuk mencari rute dari satu lokasi ke lokasi lainnya di lingkungan kampus. Terdapat enam lokasi, yaitu A, B, C, D, E, dan F. Program ini bisa menampilkan hubungan antar lokasi, melakukan pencarian menggunakan BFS dan DFS, serta mencari rute terpendek menggunakan algoritma Dijkstra.

### 4. Sistem Pengelolaan Data Mahasiswa Menggunakan Hash Table
Deskripsi:
Program ini dibuat untuk menyimpan data mahasiswa menggunakan NIM dan nama. Pengguna bisa menambahkan, mencari, menghapus, dan melihat data mahasiswa. Program ini menggunakan Hash Table dengan ukuran 20 dan metode Double Hashing untuk mengatasi collision ketika ada beberapa data yang memiliki indeks awal sama.
